# The Rise of China — Interactive Scrollytelling

An interactive data visualization and scrollytelling web project exploring China's modern socioeconomic transformation, urbanization, and development milestones.

🔗 **Live Demo:** [sirjimmylin.github.io/rise-of-china](https://sirjimmylin.github.io/rise-of-china/)

---

## 📖 Overview

This project uses scroll-driven storytelling to walk through key historical and economic shifts in modern China—from the founding of the People's Republic to rapid urban development and technological innovation. 

Key themes covered include:
* **Historical Context:** The proclamation of the People's Republic of China and early foundations.
* **Socioeconomic Indicators:** Long-term trends in Human Development Index (HDI), life expectancy, and poverty reduction.
* **Urbanization & Modernization:** Visual comparisons of rapid urban growth in major hubs like Shanghai and Shenzhen, alongside emerging technologies.

---

## 🛠️ Tech Stack

* **HTML5** (`index.html`) — Semantic page structure and narrative layout.
* **CSS3** (`styles.css`) — Responsive styling, typography, and sticky scrollytelling layouts.
* **Vanilla JavaScript** (`scripts/scrolly.js`) — Scroll event listeners and dynamic visual transitions.
* **GitHub Pages** — Static site hosting.
